# 옷의 간단한 수선 — 손바느질 배우기

실과 교과서 '옷의 간단한 수선' 단원용 수업 슬라이드 + 학습 웹앱 (정적 HTML, 태블릿 기준).

- `index.html` 시작 화면
- `slides.html` 웹 슬라이드 (탭/스와이프/방향키)
- `app.html` 바느질 연습장 (홈질·박음질·시침질 시범 애니메이션 + 펜으로 앞면·뒷면 바느질: 시작매듭→바느질→끝매듭→정리, 홈질·박음질·시침질·단추 달기 미션 + 도구 퀴즈·순서 맞추기)
- `art.js` 직접 그린 SVG 그림 모음

GitHub Pages: Settings → Pages → main / root.
